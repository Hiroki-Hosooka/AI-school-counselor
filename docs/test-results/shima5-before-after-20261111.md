## 3. 決めてほしいこと

- **謝罪が作り直しでも残る**: 作り直しは1回だけ(5.19)なので、2回目も謝ると、そのまま出る。案は2つ。
  1. いまのまま(残ったら記録だけ。プロンプトの指示を強める)
  2. 作り直しても残ったら、謝罪の言葉を含む文だけをコードで消す(残りの文が受け止めと問いになっている場合だけ。今回なら「伝えなきゃと思うほど焦ってしまって、今はそれどころじゃないんだよね。…」から始まる)
