## 1. 状態の持ち方(段階ごとの応答が有効なとき)

## 2. 否定の見分け方

| A 生きたい気持ち | 11-4 の語表との照合(危機のキーワードと同じ正規化) | 明示的な否定 |

| C 最小化・引き下がり | `judgeWithdrawal` が「引き下がり」と判定(1回) | キーワードによらない否定 |

- 念押し(否定の語の直後の「じゃない」「ではない」「じゃねえ」、「本気」「本当に」「マジで」)は否定に数えない。

## 3. 気持ちのスケーリング

- **出すとき**: 段階2で否定が出たとき(`step1`・`step3`・`done` のどれでも)
- **回数**: 1回の会話で**2回まで**。直前のAIの返事がチップ(どの組でも)だったときは出さない
  (そのターンの否定は「選ばずに自由に書いた」と同じく、下げずに流れを続ける)→ Q13
- **AIの返事**: 指示書 2-2 の文面(仮)。否定が A のときは、両方の気持ちを受け止める文面にする(嶋先生の
  「どっちの気持ちもあるのかな」の形)。A 用の文面(仮)を別に1つ持つ → Q14
- **数字だけの発言**: 「2」「２」「2です」「2かな」「2くらい」を選んだものとして扱う。それ以外(「2と3の間」など)は自由文
- **選んだあと**
  - 1-1 に当たる(明示的な否定×1・2、キーワードによらない否定×1) → 段階1に下げる(`lowered`)。
    残りの固定の文面は出さず、気がかりの指示(Tier B)+危機のあとの指示で生成し、気づかいのカード(折りたたみの窓口つき)を添える
  - 当たらない → 選んだ数字を受け止める一言(固定・仮)+止まっていた次の文面(`step1` からなら2通目+3通目、
    `step3` からなら3通目をもう一度出すのではなく、答えを待つ状態に戻る)→ Q15
  - `done` から来たときに当たらない → 受け止める一言だけを固定で出し、次から生成に戻る
- 下げても**通知と記録は取り消さない。** 打ち明けたターンの段階2はそのまま残る
- `lowered` のあとに、はっきりした危機のサイン(キーワード・受動パターン・分類器の危機判定)が出たら段階2に戻して通知する。
  固定の文面はもう出しているので、今の「2回目以降の短い1通」(1回の会話で1回まで)→ そのあとは危機の状態の生成。
  分類器の watch 相当だけでは戻さない → Q16

## 4. 危機の流れの文面

### 4-1 2通目(心配)+3通目

吹き出しを分けて、1〜2秒(1.5秒)おいて1つずつ出す。

1. 「{心配なこと}が、とても心配です。」
2. 「あなたのために、その気持ちを、カウンセラーの先生など、あなたの声が届く人とも一緒に考えてほしいなと思っています。」
3. 「ここで話すのをやめてほしいわけじゃないよ。下に、話せるところものせておくね。」+ 危機カード(窓口)
4. 3通目(候補 A/B/C のどれか。設定 `CRISIS_STEP3_VARIANT`)

- {心配なこと} は、**打ち明けたターン(と1通目への返事)で当たったキーワード・受動パターンの組**で決める(分類器は変えない)。
  - 希死念慮: 死にたい・消えたい・いなくなりたい・自殺・自死・生きる意味・終わりにしたい・楽になりたい・受動パターン
  - 自傷・過量服薬: 自傷・リストカット・リスカ・オーバードーズ・切っちゃう・傷つけ
  - 暴力・虐待: 殴られ・叩かれ・蹴られ・暴力・虐待・怒鳴られ
  - 性被害: 触られ・脱がさ・性的
  - 重大ないじめ: 晒され・お金を取られ・カツアゲ・恐喝・脅され・無視され続け
  - 種類不明: 助けて・たすけて、分類器だけで危機と判定したとき、積み重なりで始めたとき
  - 複数の組に当たったら: 希死念慮 > 自傷 > 性被害 > 暴力・虐待 > いじめ の順で1つ選ぶ → Q6
- 吹き出しは、サーバが配列で返し、画面側で間をおいて表示する。DBには吹き出しごとに1行ずつ保存する
  (再読み込み・管理画面で同じ並びに戻るように)→ Q8
- 「わたしだけで受け止めるには重い」と「どんなところが話しにくい?」の問いは消す
- 生成で言い換えてパーソナライズする案(今回は実装しない。安全の担保の案だけ): 生成させるのは {心配なこと} の
  名詞句だけ(30字以内)にし、(a) 出力チェック・危機の生成の追加チェックを通す、(b) 方法・手段・数字・固有名を含まない、
  (c) 本人の書いた語を引用しない、(d) 通らなければ種類ごとの固定の文面に戻す。固定の文の型(1〜4)は生成させない

### 4-2 3通目への答え(今の判定 `judgeTeacherAnswer` を「相談先や大人」に合わせて言い直す)

| 答え | 返すもの |
|---|---|
| 前向き | 指示書の文面(仮)。そのあと、本人が望めば作戦会議(生成。手法を並べない、を指示に足す) |
| どちらでもない | 指示書の文面(仮)。そのあと生成 |
| 後ろ向き | 受け止め+理由を選んでもらう文面(仮)+ 組Bのチップ |

- 組B: B1 → 深追いしない・理由を聞かない、を指示に足して生成(固定の文は出さない)/ B2 → 短い前置き(仮)+組Cのチップ → Q17
- 組C: 選んだ内容をそのまま受け止める一言(C1〜C7 ごとに固定・仮)。次のターンから、選んだ内容と「共感/解決」を指示に入れて生成 → Q5・Q17
- 自由に書いたとき(チップを押さない): チップの組はもう出さず、危機のあとの指示つきの生成で受ける
- **チップを押したターンは、分類器にかけない**(ラベルは固定の文で、本人の言葉ではないため)。段階はそのまま → Q18

### 4-3 チップの仕組み

- サーバの応答に `choices: [{id, label}]` と `choice_set`(`scaling` / `B` / `C`)。サーバはいま待っている組を
  `sessions.pending_choice_set` に持ち、送られた `choice_id` がその組のものでなければ自由文として扱う
- 画面: AIの返事の下にボタン。押すとラベルを本人の発言として表示し、`choice_id` を送る。入力欄はいつでも使える
- 同じ組は1回の会話で1回まで(スケーリングは3章)。B → C は指示書の流れどおり続けて出す。それ以外の2つの組は続けて出さない → Q13
