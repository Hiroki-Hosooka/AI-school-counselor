# 「人につなぐ必要がある」印(設計と実装)

2026年11月9日。人の案(下の1〜5章はその案のまま)を、設定 `REFERRAL_FLAG=on` のときだけ動く形で実装した(**既定は無効**。人が決めた)。
数値と文面はすべて仮で、心理士さんの確認と開発用の台本での調整を経て決める。本番で有効にするのは Vercel の環境変数(人の作業)。
有効にする前に `db/schema.sql` の20節を Supabase で実行する(未実行でも会話は止まらないが、前のターンの手がかりを数えられない)。

## 実装のまとめ(6章)

| 何を | どこで |
|---|---|
| 判定(手がかりと段階の合図を、根拠の引用つきで抜き出す。軽いモデル1回・思考の上限つき) | `src/referral.mjs` の `judgeReferralCues`・`REFERRAL_JUDGE_PROMPT` |
| 引用の確かめ(今の発言に無い引用・本人以外・知らない種類は捨てる) | `cleanReferralJudgment` |
| 点数と段階(会話全体で数える。同じ領域は1点。打ち消しは2ターン以上で1点。一時的と言ったターンの領域・期間は数えない) | `referralState` |
| 印が付いた会話の指示(仮) | `referralBlock`・`REFERRAL_BLOCK_PROVISIONAL` |
| 研究の指標(段階を1つ以上進めた割合・段階2/3まで進んだ割合) | `referralMetrics`(管理画面の一覧の上) |
| 判定を呼ぶ・記録する・指示を渡す | `src/app/api/chat/route.ts`(危機の判定と同時に走らせる) |
| 記録 | `messages.referral`(20節。発言の行 = そのターンの判定、返事の行 = 点数と段階) |
| 管理画面 | 一覧のバッジ(点数・段階 始まり→今)と研究の指標、会話の中の手がかりと引用・点数の内訳 |
| テスト | `scripts/test-referral.mjs`(3章の例・画面と同じ API の経路) |

**実装で決めたこと(案に書かれていなかったところ)**
- **判定するターン**: 本人が書いたターンだけ毎回(人が選んだ)。チップ・インテークの数字・中身の無い短い返事(「うん」等)では判定しない。危機の分類器と同時に呼ぶので、待ち時間は増えない。費用は1ターン約0.1〜0.3円の見込み。
- **危機の分類器のプロンプトは変えていない**(CLAUDE.md 5.16)。別の判定にした。
- **危機が先**: 本人の危機のターン・危機のあと・段階ごとの応答のときは、印の指示を付けない(記録は続ける)。危機の文面と窓口のカードは印では出さない。
  「眠るために薬を多めに飲んでる」が危機キーワード(過量服薬)に当たれば、危機の流れになる。
- **インテーク中は指示を付けない**(台本に自由な進め方を混ぜない。CLAUDE.md 5.13)。インテークは話を聞く時間でもある。記録は続ける。
- **まず聞く**: 印が付いたターンは「まず聞く」だけ。次のターンから、段階の一歩の指示を付ける。
- **段階は、本人の言葉の引用があるときだけ進む**(判定の stage_signal にも引用を求める)。モデルの返事の申告では進めない。
- **断った相手**(`src/declined.mjs`)は、段階2の候補に挙げない。
- **気がかり(段階1)+相談できる人がいない** は、気がかりの判定があったターンと「相談できる人がいない」が同じ会話にあれば付く。
- **印は会話のあいだ残る**(点数が後で下がることはない。手がかりは足し算だけ)。新しい会話では数え直す。
- 職員への通知は出さない(既定。学校との取り決めで決める)。

## 0. 位置づけ

- 危機(段階2:希死念慮・自傷・虐待などの打ち明け)とは別の印。緊急性ではなく、**人の支援につないだ方がよい状態か**を表す
- 印は診断ではない。AIは病名を出さず、診断もしない
- 数値はすべて仮。心理士さんの確認と、開発用の台本での調整を経て決める

## 1. 手がかりの3つのまとまり

### 1-1 領域(何が起きているか)

同じ領域の手がかりがいくつ出ても、その領域は1点として数える。

| 領域 | 手がかりの例 | 根拠 |
|---|---|---|
| A 気分・意欲 | 気分が沈む、楽しめない、興味がわかない、疲れが取れない、気力が出ない | PHQ-A(子ども向けのうつのスクリーニング)の項目 |
| B 眠り・食事 | 眠れない、何度も目が覚める、寝すぎる、食欲がない、食べすぎる | PHQ-A の項目。文部科学省の健康観察の資料 |
| C 不安・緊張 | 不安が止まらない、落ち着かない、急に息が苦しくなる、こわさが続く | GAD-7(不安のスクリーニング)の項目 |
| D 現実感・ぼんやり | 現実感がない、自分を外から見ている感じ、時間が抜け落ちる、ずっとぼーっとする | 解離の症状として一般に知られるもの(要文献確認) |
| E 自分への見方 | 自分はだめだ、迷惑をかけている、価値がない | PHQ-A の項目。自殺の対人関係理論の「負担感」 |
| F 体の不調 | 頭痛・腹痛・吐き気が続く、朝起きられない | 文部科学省の健康観察の資料 |

### 1-2 程度(どれくらいか)

| 手がかり | 点 | 例 |
|---|---|---|
| 生活への影響 | **2** | 学校に行けない日が続く、身の回りのこと(食事・水分・入浴)ができない、勉強や部活が手につかない |
| 続いている期間が2週間くらい以上 | 1 | 「ここ2週間」「先月から」「ずっと」 |
| 本人のつらさが4・5(インテークのつらさ、または本人の言葉) | 1 | 「限界に近い」「もう耐えられない」 |
| 悪くなってきている | 1 | 「前より」「どんどん」 |

### 1-3 支え(ひとりで抱えているか)

| 手がかり | 点 | 根拠 |
|---|---|---|
| 相談できる人がいない、いても話せていない | 1 | 田中さん(相談できる人がいなければ孤立している)。対人関係理論の「所属感の減弱」 |
| 打ち消し・強がりがくり返される | 1 | 嶋先生(「大丈夫」は「もう結構です」の意味でも使われる)。自治体の教員向け資料(子どもの「大丈夫」は本当は大丈夫ではないことがある) |

## 2. 印を付ける条件

### 2-1 点数で付ける

**合計が4点以上**で印を付ける。ただし、次の両方を満たすこと。

- 領域(1-1)が少なくとも1つある
- 程度(1-2)が少なくとも1つある

領域だけ、または支えだけでは、どれだけ点が多くても印を付けない。つらい気持ちの言葉が多いだけの相談で印が付くのを防ぐため。

### 2-2 それだけで付ける手がかり

| 手がかり | 例 |
|---|---|
| 食べることへの強いこだわりや、食べたあとに吐く | 「食べたら吐いてる」「何日も食べてない」 |
| 市販薬などの使いすぎ(危機の打ち明けに当たらないもの) | 「眠るために薬を多めに飲んでる」 |
| 学校に行けない状態が続いている | 「もう1か月行けてない」 |
| 気がかり(段階1)の打ち明けがあり、相談できる人がいない | 「生きてる意味がない」+「話せる人がいない」 |

### 2-3 数えないもの

- 第三者(友達・家族)の状態
- 誇張・冗談の表現(「テストやばすぎて死ぬ」)
- 一時的なもので期間が短いと本人が言っているもの(「テスト前だから眠れない」)。期間の点は付けない。ほかの点も、期間が短いと明らかなら数えない
- 根拠が今の会話の中の、本人の言葉に見つからないもの(分類器は、手がかりごとに根拠の部分を抜き出す)

## 3. 当てはめた例(`scripts/test-referral.mjs` で確かめている)

| 相談 | 領域 | 程度 | 支え | 合計 | 印 |
|---|---|---|---|---|---|
| 2週間眠れず、家でぼーっとして水も飲まない。「大丈夫」をくり返す(ログ 86130eef 11/04) | A・B・D=3 | 生活への影響2、期間1=3 | 強がり1 | 7 | 付く |
| テスト前で眠れない。終われば戻ると思う | B=1 | なし | なし | 1 | 付かない |
| 仲間外れでつらい。一人になるのが怖い(期間・生活への影響の言及なし) | C=1 | なし | なし | 1 | 付かない(希死念慮があれば危機の判定で扱う) |
| 自分はだめだ、迷惑ばかり。ずっと前から。相談できる人はいない | E=1 | 期間1 | 相談できる人なし1 | 3 | 付かない(4点に届かない。気がかりとして見守る) |
| 朝起きられず、1か月学校に行けていない | B・F=2 | 生活への影響2、期間1=3 | なし | 5 | 付く(2-2でも付く) |

4つ目の例は、印が付かない境目にある。心理士さんに、ここで付けるべきかを確かめる。

## 4. 印が付いたあと

### 4-1 会話のゴール

印が付いた会話では、**人に相談できるようになること**を、AIが会話の向かう先として持つ。

- このゴールは、AIが心に持っておくものにとどめ、相談者に言葉で示さない
- 相談者がインテークで答えたゴール(吐き出したい、整理したい など)を優先し、話を十分に聞いてから、人につなぐ方へ進む(田中さん:つなぐのが早すぎると、突き放された感じになる)

### 4-2 段階

| 段階 | 状態 | AIがすること | 根拠 |
|---|---|---|---|
| 1 気づく | 「大丈夫じゃないかも」と、自分の状態を言葉にできる | 強がりの奥に触れる。本人が書いた具体的なことを挙げて、心配を伝える | 嶋先生(「大丈夫」は文字どおりではない、「心配」で伝える) |
| 2 思い浮かぶ | 話せそうな人が一人、思い浮かぶ | 相談できる人がいるかを確かめる。いなければ、保健室の先生やスクールカウンセラーを候補として示す | 田中さん(相談できる人の確認) |
| 3 決まる | 誰に、いつ、どう切り出すかが決まる | 一緒に作戦を立てる。「この画面を見せるだけでも伝わる」と伝える | 石田先生(作戦会議) |
| 4 話す | 実際に話す | 会話の外で起きること。次に来たときに、責めない形で様子を聞く | 再訪の扱いの決まり |

- 会話の始まりの段階は、本人の言葉から決める。すでに「大丈夫じゃない」と言っている人は、段階1を飛ばして段階2から始める
- 段階は、本人の言葉で確かめてから進める。AIが「進んだ」と思い込んで先に行かない

### 4-3 守ること

- **1つの返事で、段階を2つ以上進めようとしない。** 気づいた直後に「じゃあ誰に話す?」と畳みかけない
- **相談者が断ったら、その会話では段階を進めようとしない。** 「今は相談したくないんだね」と受け止め、扉を開けたまま終える(田中さん)。同じ会話で再び勧めない
- 危機の文面と窓口のカードは出さない(画面下の常設の表示はそのまま)
- 病名を出さない。診断しない

### 4-4 記録と管理画面

- 印はその会話のあいだ残る
- 管理画面で、印の付いた会話、点数の内訳、**会話の始まりと終わりの段階**を見られるようにする
- 職員への通知は、学校との取り決めで決める(既定は通知しない)

### 4-5 研究の指標

印が付いた会話のうち、**何割が段階を1つ以上進めたか**、**何割が段階2・3まで進んだか**を記録する。

## 5. 心理士さんに確認すること

1. 領域・程度・支えの手がかりに、過不足はないか
2. 4点という線は妥当か。3の4つ目の例(自己否定・長期・孤立)は印を付けるべきか
3. 2-2の「それだけで付ける手がかり」に、加えるべきものはあるか
4. 印が付いたときのすすめ方の言葉と、4つの段階の分け方(特に、段階1「気づく」をどう促すか)(`src/referral.mjs` の `REFERRAL_BLOCK_PROVISIONAL`)
5. 印の付いた会話を、職員に知らせるべきか

### 7-1 判定(`scripts/test-referral-judge.mjs`。各2回)

| | 1回目 | 指示を直したあと(2回目) |
|---|---|---|
| 1文ごと: 出てほしい手がかりの取りこぼし | 0 / 32 | 0 / 32 |
| 出てほしくない手がかり(誇張・第三者・ふつうの文)が出た | 0 | 0 |
| 一時的と言った手がかりを数えなかった | 2 / 2 | 2 / 2 |
| 段階の合図(気づく・思い浮かぶ・決まる・話した・断った)が合った | 10 / 10 | 10 / 10 |
| 会話: 印が期待どおり | 14 / 14 | 14 / 14 |

- 1回目は、案の例5(朝起きられず、1か月学校に行けていない)が「それだけで付く手がかり」(学校に行けない状態が続く)だけで付き、点数は1点だった。
  「もう1か月学校に行けてない」から「学校に行けない状態」しか出さず、生活への影響・期間を出していなかったため。
- 判定の指示(`REFERRAL_JUDGE_PROMPT`)に「1つの言葉が複数の手がかりに当たるときは、当たるものを全部出す」を足した。2回目は4点(F・生活への影響・期間+それだけで付く手がかり)。
- 例1は6点(3章の手計算は7点。「気分・意欲」の手がかりは出なかった。印は付く)。例4(境目)は2回とも3点で付かない。

### 7-2 印が付いたあとの返事(`scripts/test-referral-replies.mjs`。画面と同じ API の経路・偽の DB)

`docs/test-results/referral-replies-20261109.md` に、全部の返事と、付いた指示・危機の判定を残した。最終の判断は人が読んで行う。
- **r1**(眠れない・ぼーっと・行けない・「大丈夫」をくり返す → 「母になら話せるかも」):
  印が付いたターンは「まず聞く」になった。段階は1つずつ進んだ: 気づく → 「しんどいかも」で思い浮かぶ → 「母になら」で決まる。
  決まったあとの返事は、切り出し方の作戦だった(「この画面をそのまま見せて」を含む)。
- **r2**(食べたあとに吐く): 危機の分類器が1ターン目を本人の危機と判定した。危機の流れが先なので、印の指示は付かなかった(設計どおり。記録は続く)。

- 機械の目安: 返事15件のうち、病名らしい言葉・電話番号・「いつでも」・2つ以上の問いはどれも0件。
