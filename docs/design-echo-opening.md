# 返事の冒頭の言い直しを減らす(設計)

2026年11月1日。相談ログのレビューで「返事の冒頭の繰り返しが、そのまますぎて不快」と指摘があった。
多くの返事が、最初の一文で相談者の文をほぼそのまま言い直している
(例: 「両親が勝手に私の進路を決める。勝手に塾に入れて…」→「進路も塾も勝手に決められて、話を聞いてもらえないと感じているんだね。」)。
原因は、5.19 の「返事には相談者が書いた具体的なことを入れる」決まりが、言い直しの形に偏ったことと考えている
(プロンプトの例も「みんなが談笑してる横で、自分だけ手を動かしてるんだね」という言い直しの形だった)。

## 1. プロンプトの決まり(`src/flow.mjs` の `FLOW_RULES_BLOCK`・`src/generate.mjs` の「応答の作り方」・`src/crisis-turn.mjs`)

- 相談者の文を言い直すのは3〜4回に1回くらいまで。拾うのは一番気持ちのこもった一語か一句だけ
- 相談者の文を「」で丸ごと引用して返事を始めない
- 具体的なことに触れるときは、その中身を、問いや次の一言の中で使う(例:「塾も、相談なしで決まったの?」)
- 相談者の発言が短いときは、短い相槌(「そっか」「うん、怖いよね」)で返してよい
- 5.19 の例を、言い直しの形から問いの形に替えた。受け止めの形の並びからも「言い換え・要約」を「ときどき」に下げた

## 2. 出力チェック(`src/flow.mjs` の `echoOf`)

返事の最初の一文と、相談者の直前の発言の重なりを、文字の2つ組(バイグラム)で測る。

- `shared` = 最初の一文の2つ組のうち、相談者の直前の発言にもあるものの数
- `ratio` = `shared` ÷ 最初の一文の2つ組の数(最初の一文のうち、相談者の言葉でできている割合)
- 相談者の直前の発言が8文字以下(「うん」「怖いの」)なら、その前の発言とも比べる(短い返事のあとに、前の発言を言い直す形があったため)
- 記号・空白・小さい「っ」は除いて比べる

### 閾値(提案。10/28・10/11 の相談ログの返事55件を読んで決めた)

| 判定 | 条件 | 扱い |
|---|---|---|
| 言い直し | `shared` ≥ 7、または `shared` ≥ 5 かつ `ratio` ≥ 0.4、または引用 | 記録(`記録のみ:冒頭の言い直し`) |
| 強い言い直し | `ratio` ≥ 0.5 かつ `shared` ≥ 6 | 作り直し(1回) |
| 引用で始める | 最初の一文の「」の中身が、相談者の発言の6文字以上をそのまま写している | 作り直し(1回) |
| 続いた言い直し | 言い直しで、直前2回の生成した返事にも言い直しがある | 作り直し(1回。3回に1回までにする) |

決め方: 55件を読んで、言い直しだと感じたもの(「いじりすぎちゃったんだね」← 「ちょっといじりすぎちゃった」、
「進路も塾も勝手に決められて…」など)と、一語・一句を拾っただけのもの(「6点なんだね」`shared` 1、
「打開したい、という強い思いがあるんだね」`shared` 4〜5・`ratio` 0.29、「そっか、わかんないよね」`shared` 4)が分かれるところに置いた。
言い直しでも、相談者の言葉に AI の言葉を足して長くした形(「否定されるのが嫌だなって感じるくらい、すごく怖いんだね」`ratio` 0.29)は
`ratio` が低くなるので、`shared` の数でも拾う。

**作り直しは強い言い直し・引用・続いた言い直しだけにした。** 言い直しをすべて作り直すと、指示の「3〜4回に1回はよい」と合わないため。
作り直しはフェーズ2の生成(`flowCheck` の理由 J)。危機のターン・インテークでは記録だけする(危機の出力チェックを優先する)。
チップを押したターンは比べない(相談者の言葉ではないため)。

### 管理画面

- 会話の詳細の「会話の流れ(このセッション)」に、冒頭の言い直しの数と割合(目安 25%以下)
- 一覧の上の「モデルの状態」の行に、直近1時間・24時間の冒頭の言い直しの割合(印の付いた返事 ÷ 返事。この版より前の返事には印が無い)

## 3. 検証

- 10/28 の5件のログで、修正前(本番で実際に出た返事)と修正後(同じ生徒の発言を画面と同じ API の経路で流す。無料枠・合成)の
  「最初の一文が言い直しの割合」を比べる。目安は 25%以下。`scripts/analyze-echo.mjs`
- 「具体への言及」の割合(軽いモデルの採点。`scripts/_lib/flow-rater.mjs`)が大きく下がっていないことも確かめる
- 最終の判断は、相談した本人が読んで行う(修正後の返事の全部を `docs/test-results/echo-opening-20261101-after.md` に書き出す)

## 4. 変えていないもの

安全層・危機の判定・危機の固定の文。5.19 の他の決まり(受け止めのみは2回まで・汎用の言葉・まとめの形)。
