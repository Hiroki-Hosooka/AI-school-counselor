# 会話が展開しない問題の修正

## 0. 前提

### 0-1 きっかけ

開発メンバーが実際に相談してみたログ(相談ログ 16f362dd、2026/10/11)で、次の3つの違和感が出た。

- 同じことを同じように何度も繰り返されて、イラッとする
- 質問してくれず、ずっと受け止められると、何を話せばいいかわからない
- 会話の展開がなく、どうすればいいかわからない

このログを `docs/review-logs/2026-10-11-16f362dd.md` として保存し、作業前に必ず読むこと(個人を特定できる情報が含まれていないかを確かめてから保存する)。

### 0-2 ログで起きていたこと

| 現象 | ログの箇所 |
|---|---|
| 「問わず受け止めのみ」が4回続いた | 9〜12ターン |
| 「ずっと(一人で)頑張ってきたんだね」と同じ意味の文が4回出た | 7・8・11・12ターン |
| 相談者が言っていない強い言葉を足した(「取り残されて一人きり」「逃げ場のない」「心がすり減って」) | 9・11・12ターン。相談者は「虚無になる」と書いただけ |
| インテークのゴール「吐き出すことと整理することの両方」のうち、整理が一度も始まらなかった | 6ターン以降すべて |
| 判定したモード(傾聴+認知行動療法)の、認知行動療法の部分が一度も使われなかった | 6ターン以降すべて |
| 「一回整理してみたい」と言ったのに、まとめをしないまま受け止めに戻った | 8ターン |

**禁止表現は一つも出ていない。** これまでの自動テストは「してはいけないこと」を中心に測っていたので、この種の問題は見つからなかった。

### 0-3 原因と考えていること

1. **「迷ったら問わずに受け止めだけ」の指示が効きすぎている。** 会話が深まるほどAIは迷いやすくなり、受け止めだけが続く
2. **コンプレイナント型の読み違い。** 設計の「本人に行動を求めない」を、AIが「問わない」と受け取っている。石田先生はこの型の相談に「そう感じるエピソードがあったの?」「その時、どうしてほしかったの?」と問いを使っていた(ナレッジ V4・V5)
3. **ゴールとモードが、会話の中で使われていない。** インテークで集めた情報が、そのあとの応答に効いていない

### 0-4 進め方

- 設計→私の確認→実装→検証、の順で進める。設計を見せるまで実装しない
- 危機の流れ(段階2の固定の文面・チップ)と、安全層の決まりには触れない
- 検証は無料枠のキーで、合成データだけを使う

## 1. 受け止めだけの返事を続けない

### 1-1 決まり

- 「問わず受け止めのみ」(question_level = none)の返事は、**続けて2回まで**
- 3回目は、次のどれかにする
  - 問い(1つだけ)
  - まとめ(3章)
  - 進め方を選んでもらう選択肢(4章)
- プロンプトの「迷ったら下の層に留めるか、問わずに受け止めだけにする」を、次のように書き換える
  - 「迷ったら、問いの層を下げる(事実や本人の感じ方を聞く問いにする)。問わないことを選ぶのは、相談者がそれを望んだとき、または直前に問いを重ねすぎたときだけ」

### 1-2 例外

- 相談者が「聞いてほしいだけ」「アドバイスはいらない」と言った場合(傾聴のモード)は、問いを減らしてよい。ただし、**次につながる一言(1-3)は必ず付ける**
- 危機の流れの固定の文面は、この決まりの対象外

### 1-3 「次につながる一言」

問いでなくても、相談者が次に何を書けばいいかの手がかりを、返事の最後に必ず置く。石田先生の「『そうなの』の次に一言ほしい」(ナレッジ IS4)。

例:
- 「その時のこと、もう少し聞かせてくれる?」
- 「続けて話してくれてもいいし、別のことでも大丈夫だよ」
- 「〇〇と△△、どっちの方が近い?」

「その気持ち、もう少し聞かせてもらえる?」のような汎用の一言だけを毎回付けるのは避け、相談者の直前の言葉を使う。

### 1-4 安全との関係

ここでいう問いは、出来事・考え・気持ち・望みを聞くもの。**危険度を確かめる問いは、これまでどおりしない**(CLAUDE.md 5.2)。段階1以上のときも、この区別は変わらない。

## 2. コンプレイナント型の扱いを直す

- 「行動を求めない」と「問わない」は別だと、プロンプトに明記する
- コンプレイナント型のときに使う問いとして、石田先生の逐語(ナレッジ V4・V5)を、参照の優先度を上げて渡す
  - 「そう感じるエピソードがあったの?」
  - 「その時、どうしてほしかったの?」
- 相談者が誰かや状況を責めているとき、同調しない(CLAUDE.md 5.1)。今回のログの「自分しかできないし誰もやってくれない」のように、本人の見方が狭まっている言葉を、AIが強める形で返さない。出来事を聞くか、本人の望みに角度を変える

---

## 3. まとめを、実際に行う

### 3-1 いつ

- これまでの区切りの仕組み(前回の区切りから6ターン)に加えて、次のときにもまとめを提案する
  - 相談者が「わからない」「なんで〜してるのか」のように、意味を見失った言葉を出したとき
  - AIが「整理してみたい」と言ったとき(言ったら、そのターンで必ずまとめる)

### 3-2 まとめの形

嶋先生の中間まとめ(ナレッジ T16)と、石田先生の「一回まとめてみようか」(ナレッジ IS8)に沿う。

1. まとめてよいかを一言たずねる、または「一回まとめてみるね」と断る
2. 相談者の言葉を使って、出てきたことを2〜4個並べる
3. 「合ってるかな?」と確かめる
4. 「ここまで話してみて、何か感じたことってある?」と、本人が気づきを言葉にするきっかけを作る

- AIが結論を言い切らない
- `did_summarize` は、この形を満たしたときだけ true にする。「整理してみたい」と言っただけでは true にしない

---

## 4. ゴールとモードを、会話の中で使う

### 4-1 インテークのゴールを覚えておく

- インテークの「期待するゴール」を、フェーズ2の毎ターンのプロンプトに入れる
- ゴールに「整理」が含まれる場合、吐き出す話が3〜4ターン続いたら、整理に移ることを提案する。提案はチップでもよい(例:「このまま話したい」「一緒に整理してみたい」)。チップの文面は仮

### 4-2 判定したモードの「最初の一手」

判定したモードの最初の一手を、フェーズ2に入ってから3ターン以内に一度は使う。相談者が拒んだら、無理に続けない。

| モード | 最初の一手(例) |
|---|---|
| 認知行動療法 | 出来事・そのときの考え・気持ちを分けて聞く。「その瞬間、頭の中ではどんなことが浮かんでる?」 |
| 解決志向 | うまくいっている時・例外を聞く。「少しでもましだった日ってあった?」 |
| ナラティブ | 問題を本人から切り離す(技法名は言わない) |
| 傾聴 | 問いは減らすが、次につながる一言は付ける |

複合モード(今回の「傾聴+認知行動療法」)では、傾聴で受け止めたあと、認知行動療法の一手に移る。

---

## 5. 同じ言い回しを繰り返さない

- 受け止めの形を回す:くり返し・言い換え・要約・気持ちの明確化・是認・問い
- 返事の終わり方が、直前2回と同じ形(「〜んだね。」で終わる、など)にならないようにする
- **出力チェックに追加**:直前3回のAIの返事との言い回しの重なりを測り、一定以上なら1回だけ作り直す。重なりの測り方と閾値は、設計で提案すること。今回のログの7〜12ターンが、作り直しの対象として検知されること
- 「ずっと〜頑張ってきたんだね」のような、同じ意味の受け止めを、1回の会話で何度も出さない

---

## 6. 相談者の言葉より重くしない

- 相談者が言っていない強い言葉(「すり減る」「限界」「逃げ場」「取り残され」「耐えられない」など)を、受け止めの中で足さない
- 相談者の言葉をそのまま使う(既存の「言い換えすぎない」の決まりを、強める)
- **記録のみのチェック**:相談者の発言に含まれていない強い感情の言葉を、AIの返事が使っていたら記録する。作り直しはしない。言葉のリストは設計で提案すること

---

## 7. ログの表示

- 相談ログと管理画面の内部判断の欄に、**安全の段階(0/1/2)と、その根拠**を表示する
- あわせて、受け止めのみが何回続いたか、前回のまとめから何ターンか、を表示する
- 今回のログの「なんで頑張ってるのかわからない」が、どの段階と判定されていたかを確かめて報告する

## 8. 検証

### 8-1 今回のログの再現(無料枠)

- 今回のログの生徒の発言(1〜12ターン)を、固定の台本として流し、修正前と修正後のAIの返事を比べる。各3回
- 比べるもの
  - 受け止めのみが続いた最大回数
  - 直前の返事との言い回しの重なり
  - まとめが入ったか、入ったなら何ターン目か
  - 認知行動療法の最初の一手が入ったか
  - 相談者が言っていない強い言葉の数
- 修正後の返事の全文も、私が読めるように書き出す

### 8-2 自動テストに「会話が機能しているか」を足す

ペルソナテストの自動判定に、次の項目を足す。

| 項目 | 合格の目安(案。設計で提案すること) |
|---|---|
| 受け止めのみが続いた最大回数 | 2回以下 |
| 言い回しの重なりで作り直した回数 | 記録のみ |
| まとめが入ったか | 10ターン以上の会話で1回以上 |
| 判定したモードの最初の一手 | フェーズ2の3ターン以内に1回 |
| 相談者が言っていない強い言葉 | 記録のみ |

### 8-3 新しいペルソナ

今回のログに近いペルソナを足す。

- **P1 よく話すが、行き詰まっている子**:学校での役割を一人で抱えている。話はよくするが、自分で整理できない。コンプレイナント型。ゴールは「吐き出すことと整理することの両方」。途中で「なんで頑張ってるのかわからない」のような、意味を見失った言葉を出す
- 生徒役には、AIが受け止めるだけのときは「うん」「そう」と短く返し、問いが来たら具体的に答える、という指示を付ける(問いがないと会話が止まることを再現するため)

有料のペルソナテストは、仮の文面が決まったときの1回にまとめて回す。今回の修正だけのために有料枠は使わない。

## 9. 守ること

- 危険度を確かめる問いはしない(CLAUDE.md 5.2)
- 同調しない(5.1)。問いを増やしても、相手を悪者にする言葉に乗らない
- 危機の流れの固定の文面とチップには触れない
- 1回の返事で問いは1つまで、という決まりは変えない
- 採用したら、CLAUDE.md に次を、根拠(相談ログ 16f362dd、石田先生 IS4・V4・V5・IS8、嶋先生 T16)とともに書き足す
  - 受け止めのみは続けて2回まで
  - 行動を求めないことと、問わないことは別
  - 「整理してみたい」と言ったら、そのターンでまとめる
- このログは、次の心理士さんとの検討会の資料にも使う。12ターン目で「先生ならどう返しますか」と聞く予定
