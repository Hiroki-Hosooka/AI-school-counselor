# 提案:危機の種類ごとに、窓口の並びを変える

> 2026年10月11日。**提案だけ(コードは変えていない)。** やり残しの一覧(`docs/leftover-audit-20261011.md`)の test1-followup 修正6。
> **どの窓口を出すか・番号は、心理士さんと学校の確認が要る。** 下の番号は、載せる前に必ず各機関の公式サイトで確かめること
> (ここに書いた番号を、確かめずに `src/app/page.tsx` に足さない)。

## 1. 今の動き

- 危機カード(`crisis-card`)・折りたたみの窓口・クロージングのカードは、どれも `src/app/page.tsx` の `HOTLINES`(5件)を、
  危機の種類によらず同じ順で出している。
  1. 24時間子供SOSダイヤル 2. チャイルドライン 3. よりそいホットライン 4. こころの健康相談統一ダイヤル 5. いますぐ危ないとき(119)
- 危機の種類は、固定応答の「〜が、とても心配です」の文を選ぶためにだけ使っている(`src/crisis-texts.mjs` の `crisisCategoryOf`。
  希死念慮 > 自傷・過量服薬 > 性被害 > 暴力・虐待 > 重大ないじめ > 種類不明)。
- 画面下の常設の窓口表示(119番・24時間子供SOSダイヤル)は、この提案でも**変えない**。

## 2. 問題

- 虐待・性被害の打ち明けに対して、その被害を専門に受ける窓口(児童相談所・性被害の窓口)が出ない。
  「どこに言えばいいかわからない」が、人につながらない理由の一つになりうる。
- 逆に、窓口をたくさん並べると選べなくなる。今の5件に足すだけにはしない。

## 3. 案

種類ごとに「いちばん上に出す1〜2件」を決め、残りは今の順で続ける(全部で5〜6件に収める)。窓口の中身(名前・番号)は、
今と同じく画面側の固定データ(確認済みの番号だけ)に持ち、モデルには書かせない(CLAUDE.md 5.15 と同じ理由)。

| 種類 | 上に出す窓口(候補。**番号は要確認**) | 理由 |
|---|---|---|
| 希死念慮・自傷・種類不明 | 今のまま(24時間子供SOSダイヤル → チャイルドライン …) | 今の並びは、この場面を想定して作った |
| 暴力・虐待 | 児童相談所 虐待対応ダイヤル「189」 | 子ども本人からの相談も受ける公的な窓口 |
| 性被害 | 性犯罪・性暴力被害者のためのワンストップ支援センター「#8891」、警察の性犯罪被害相談電話「#8103」 | 性被害を専門に受ける窓口。警察に行くかどうかを決める前でも相談できる |
| 重大ないじめ | 24時間子供SOSダイヤル(今の1番目)。学校の窓口を載せるなら学校との取り決めのあと | いじめは学校に対応の義務がある(いじめ防止対策推進法。CLAUDE.md 10節) |

- **119(いますぐ危ないとき)はどの種類でも最後に残す。**
- 第三者(友達が危ない)の場面は今のまま(本人向けの危機カードは出さない。CLAUDE.md 5.12)。

## 4. 実装するとき(決まってから)

- サーバ(`route.ts`)は、危機カードを出す返事に種類(`crisisCategoryOf` の結果)を添える。画面は種類から並びを決める。
  判断(種類の決め方)はサーバ、表示(並び)は画面、という今の分け方のまま。
- 種類ごとの並びは `src/app/page.tsx` の固定データにする(DB には置かない。窓口はナレッジではないため)。
- 確かめ: 種類ごとに並びが変わること、119 が必ず最後にあること、画面下の常設表示が変わらないこと。

## 5. 決めてほしいこと

1. 種類ごとに窓口の並びを変えてよいか(心理士さん)
2. 上に出す窓口の候補(189・#8891・#8103)でよいか、番号の確認(心理士さん・学校)
3. いじめのときに学校の窓口を載せるか(学校)
