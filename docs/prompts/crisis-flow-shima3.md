# 危機の流れの見直し(嶋先生 10/7 を反映)

## 0. 前提

- 根拠は `docs/interviews/2026-10-07-shima-3-summary.md`。作業前に必ず全文を読むこと
- この変更は、これまでの「打ち消し・引き下がりで段階を下げる」設計を**置き換える**
- **「ふつうの会話に戻る」ボタンは作らない**。会話のモードを相談者が切り替える仕組みも作らない
- 生徒に見える文面・選択肢の文言は、すべて**仮**(心理士の確認待ち)。定数名の末尾に `_PROVISIONAL` を付け、`src/crisis-response.mjs` に集める
- 段階ごとの応答は、引き続き既定で無効。ただし「危機のあと」の状態の保持と指示は本番の既定で有効(前回の決定のまま)
- 設計→私の確認→実装→検証、の順で進める。設計を見せるまで実装しない

## 1. 段階を下げる条件

嶋先生の結論:「両方の気持ちがある」ことが前提で、反対の言葉が出た理由は文字だけではわからない。
そこで、**言葉だけでは段階を下げず、本人に今の気持ちをスケーリングで選んでもらい、その結果と合わせて判断する。**

### 1-1 段階を下げてよいのは、次の2つの場合だけ

| 条件 | 否定の種類 | 気持ちのスケーリング | 下げる |
|---|---|---|---|
| ① | **明示的なキーワードによる否定** | **1 または 2** | 1段階下げる |
| ② | 否定(キーワードによらないもの) | **1** | 1段階下げる |
| それ以外 | — | — | **下げない** |

- スケーリングを選ばずに自由に書き続けた場合は、**下げない**
- スケーリングが3以上なら、どちらの否定でも**下げない**
- 下げるのは**1段階だけ**(段階2→段階1)。**段階1から段階0には下げない**(これまでの決めごと)
- 段階を下げても、**職員への通知と記録は取り消さない**。打ち明けたターンの段階2はそのまま残す
- 下げたあとに新しいサイン(キーワード・受動パターン・分類器の危機判定)が出たら、段階2に戻し、通知する

### 1-2 否定の種類(根拠は `docs/crisis-keywords-v3.md` の11章)

否定の言葉は、文献とデータに基づいて3つに分ける。**作業前に11章を必ず読むこと。**

| 種類 | 1-1での扱い | 例 | 主な根拠 |
|---|---|---|---|
| A 生きたい気持ちの表明 | 明示的な否定 | 死にたくない、消えたくない、生きたい | 死にたい気持ちと生きたい気持ちは同時にあり、その差が自殺の危険因子になる(Kovacs & Beck, 1977/Brown et al., 2005) |
| B 冗談・取り消し | 明示的な否定 | 冗談、うそ、ネタ、本気じゃない、今のなし | 否定は当てにならない(自殺で亡くなった入院患者の78%が、最後のやり取りで自殺念慮を否定していた:Busch et al., 2003)ので、単独では下げない |
| C 最小化・引き下がり | キーワードによらない否定(分類器で見つける) | 大丈夫、なんでもない、別に、もういい、忘れて | 「大丈夫」は本当は大丈夫ではないことがある(自治体の教員向け資料)。嶋先生「もう結構ですの意味で使う」 |

- AとBの語は、11-4と11-5の表をそのまま使う。正規化(ひらがな・カタカナ・長音など)は危機のキーワードと同じ仕組みで行う
- **念押しは否定に数えない**:否定の言葉の直後に「じゃない」「ではない」「じゃねえ」が続く場合(「冗談じゃない」など)、「本気」「本当に」「マジで」
- **絶望感の表現は否定に数えない**:「もういい、どうせ」「もうどうでもいい」「何やっても無駄」は、新しいサインとして分類器に判定させる(11-7)
- Cは今の `judgeRetraction` で見つける(1回の判定でよい)。**この判定だけで段階は変えない**
- 判定の記録に、否定の種類(A/B/C)と当たった語を残す

**Aのときの応答**:「死にたくない」は前の発言の取り消しではなく、生きたい気持ちの表明として受け止める。嶋先生の「どっちの気持ちもあるのかな」の形で、両方の気持ちを受け止める。生きたい気持ちを喜んで終わりにしない

### 1-3 同じ発言に、危機のキーワードと否定がある場合

例:「死にたいとか冗談だよ」

- 否定の対象としての言及とみなし、新しいサインとしては数えない。スケーリングの結果で、1-1の条件どおりに判断する
- ただし、分類器がその発言を新しい危機と判定した場合は、下げない
- この扱いは安全に関わるので、設計の段階で私に確認すること

### 1-4 下げたあとの応答

- 残りの危機の固定の文面は出さない
- 段階1の応答にする(気がかり向けの指示で生成)
- 段階1の気づかいのカード(折りたたみの窓口つき)を出す。窓口に一度もふれないまま終わらないようにするため
- 1通目の下の折りたたみの窓口、画面下の常設の窓口表示は残す

## 2. 気持ちのスケーリングのチップ

### 2-1 出すとき

- **安全の段階が2のときに、否定(どちらの種類でも)が出たとき**
- 段階1のときは、下げることがないので出さない
- 同じ会話で何回まで出してよいかは、設計で提案すること(続けて2回出さないことは必須)

### 2-2 AIの返事(仮・嶋先生の逐語に基づく)

> 最初は、つらい気持ちを伝えてくれたけど、今はちょっと反対の言葉になったね。どっちの気持ちもあるのかな。それとも、話している中で少し気持ちが変わったのかな。AIは文字どおりに受け取りやすいから、よかったら今の気持ちに近い数字を選んでみてね。

### 2-3 選択肢(仮)

インテークの「つらさ」のスケーリングと**同じ向き・同じラベル**にそろえること(1がいちばん軽く、5がいちばんつらい)。インテークの今のラベルを確認し、そちらに合わせる。

| id | ラベル(仮) |
|---|---|
| S1 | 1 いまは落ち着いている |
| S2 | 2 少しつらい |
| S3 | 3 つらい |
| S4 | 4 かなりつらい |
| S5 | 5 とてもつらい |

- 数字だけを書いた場合(「2」など)も、選んだものとして扱う
- 選ばずに自由に書いてもよい。その場合は下げない

### 2-4 選んだあと

- 1-1の条件に当たれば、1段階下げて1-4の応答にする
- 当たらなければ、下げずに危機の流れを続ける。選んだ数字を受け止める一言(「どっちの気持ちもあるんだね」など)を返してから、止まっていた次の文面に進む
- 選んだ数字は `messages` と `safety_events` に記録し、管理画面で見えるようにする(研究のデータとしても使う)

## 3. 危機の流れ

### 3-1 全体

危機の会話は、終わるのではなく、**「相談先や大人に話したいか」の問いから分岐して続く**。

| 順番 | 出すもの |
|---|---|
| 1通目 | 受け止めだけ(+折りたたみの窓口)。**相手の返事を待つ** |
| 2通目 | 「心配」の文面と窓口(3-2)。短い吹き出しに分け、1〜2秒の間をおいて1通ずつ表示する |
| 3通目 | **相談先や大人に話したいかの問い**(3-3) |
| 分岐 | 3通目への答えで分ける(3-4) |
| そのあと | 段階2のまま、危機のあとの指示つきの生成で会話を続ける。**AIから会話を終わらせない** |

- 今の2通目にある「身近な人に話すとしたら、どんなところが話しにくい?」の問いは削除する。話しにくい理由は、3-4の「話したくない」の分岐で、チップを使って扱う
- どの順番の途中でも、否定が出たら2章のスケーリングのチップを出す

### 3-2 2通目:「重い」を使わず、「心配」を使う

嶋先生:「『私だけで受け止めるには重い』は意外と傷つく言葉。シャッターガラガラって言う感覚がある」

- 「わたしだけで受け止めるには重い」を削除する
- 出力チェックに、次の表現を追加する:「受け止めるには重い」「受け止めきれない」「これ以上はできない」「負担」(AI自身の負担として言う形)
- 「心配」を使うことは、教員向けの自殺予防の対応原則(TALKの原則)の Tell「言葉に出して心配していることを伝える」とも一致する(例として「心配だよ」が示されている:`docs/crisis-keywords-v3.md` の文献18)
- 危機の固定の文面は生成しない(CLAUDE.md 5.2)ので、パーソナライズは**判定した危機の種類ごとの固定の文面**で行う

**2通目の型(仮)**
> {心配なこと}が、とても心配です。あなたのために、その気持ちを、カウンセラーの先生など、あなたの声が届く人とも一緒に考えてほしいなと思っています。ここで話すのをやめてほしいわけじゃないよ。下に、話せるところものせておくね。

**{心配なこと}の文面(仮)**
| 種類 | 文面 |
|---|---|
| 希死念慮 | いなくなりたいと思うくらい、つらい気持ちがあること |
| 自傷・過量服薬 | 自分を傷つけてしまうくらい、つらい気持ちを抱えていること |
| 暴力・虐待 | あなたがつらい目にあっていて、安全が守られていないかもしれないこと |
| 性被害 | あなたが嫌なことをされていて、安全が守られていないかもしれないこと |
| 重大ないじめ | 学校でつらい目にあい続けていること |
| 種類不明 | 書いてくれたつらさ |

- 相談者の言葉を生成で言い換えてパーソナライズする案は、今回は実装しない。どう安全を担保できるかだけ提案すること

### 3-3 3通目:相談先や大人に話したいか(仮・文面は要検討)

2通目で示した相談先(窓口)と、まわりの大人の両方について、話してみたいかをたずねる。
**この文面はまだ確定していない。** 次の候補を仮に置き、心理士の確認で決める。候補は定数として3つとも持ち、設定で切り替えられるようにすること。

| 候補 | 文面(仮) |
|---|---|
| A | 下にのせた相談先や、先生・おうちの人など、まわりの大人に話してみたいって思う? |
| B | 今日のこと、下の相談先や、先生・おうちの人のような、まわりの大人にも話せそう? |
| C | ここで話してくれたことを、下の相談先や、まわりの大人(先生やおうちの人など)にも話してみるのはどうかな。話してみたいって思う? |

- 前置き(「もうひとつ聞かせてね」など)は付けない
- 答えは自由に書いてもらい、今の仕組み(前向き/後ろ向き/どちらでもない の判定)で分ける
- AIが先生に伝えるとは言わない(本当に先生につなぐ機能は、学校との取り決めができてから)

### 3-4 3通目への答えによる分岐

**話したい(前向き)**
> (仮)そっか、話してみたいんだね。話すときは、この画面を見せるだけでも伝わるよ。

- 本人が望めば、誰に・いつ・どう切り出すかを一緒に考える(石田先生の作戦会議)。手法を並べない
- そのあとも会話を続ける

**どちらでもない**
> (仮)うん、すぐに決めなくて大丈夫だよ。話してみようと思えたときは、この画面を先生に見せるだけでも伝わるからね。

- そのあとも会話を続ける

**話したくない(後ろ向き) → ここでチップを使う**

嶋先生:「話したくない状況を説明して打つのは、話したくないのに話させられていることになる。選択肢でポチって押す方が負担が軽い」

1. まず受け止め、**なぜそう思うのかを教えてもらう**(仮・文面は要検討):「そっか、今は話したくないんだね。無理に、とは言わないよ。よかったら、そう思う理由に近いものを教えてくれる? 選ぶだけでいいよ。」
   - 理由は書かせず、チップで選んでもらう(嶋先生:説明して打たせるのは、話したくないのに話させていることになる)
   - 選ばずに自由に書いてもよい
2. **組B**(2択)を出す

| id | ラベル(仮) | 嶋先生の発言(10/7) | その後 |
|---|---|---|---|
| B1 | このやり取り自体が、いまはちょっとうっとうしい | 「このやり取り自体がもううざいって感じてるのか」 | 深追いしない。理由を聞かない。段階2のまま、本人の話したいことに合わせて会話を続ける(嶋先生:うざい人に深追いすると、より狭めてしまう) |
| B2 | 人とつながるのはおっくう。でも、もうちょっと聞いてほしい | 「人と繋がることに億劫さを感じてることを喋るんやったら、もうちょっと聞いてほしいなの」 | 組Cを出す |

組Bの2択の裏には、嶋先生が挙げた次の違いがある。組Cの選択肢と、そのあとの返し方で拾えるようにすること。

| 嶋先生が挙げた違い | 拾う場所 |
|---|---|
| 本当に何の期待もしていないから話したくない | 組C の C5 |
| 期待していないと言いつつ、実は期待している | 組B の B2(「でも、もうちょっと聞いてほしい」) |
| 話すこと自体が、自分にとって負担 | 組C の C7 |
| 「話したくない」(強い意志)と「話せない」(混乱していて、うまくまとまらない)はニュアンスが違う | 組C の C6。返し方も、話したくない人には引き、話せない人には「まとまらなくていい」と伝える |

3. B2を選んだら、**組C**(「話せない」の背景)を出す。C1〜C6は生徒から出た例で、嶋先生が「人間あるある」として選択肢に使ってよいとしたもの。C7は嶋先生自身が挙げたもの

| id | ラベル(仮) |
|---|---|
| C1 | まわりに信用できる大人があまりいない |
| C2 | 話したら、自分が崩れそうでこわい |
| C3 | 自分も悪いかもと思っている |
| C4 | どう思われるかわからない |
| C5 | 話しても意味がない気がする |
| C6 | いろいろありすぎて、うまくまとまらない・書けない |
| C7 | 話すこと自体が、いまは負担 |

4. 組Cで選んだあと
   - まず「言い当てられた」と感じられるように、選んだ内容をそのまま受け止める一言を返す
   - そのあとの返し方を、**インテークで分類した「共感を求める/解決を求める」**で変える
     - 共感を求める人:気持ちに寄り添うことを優先する。次の一歩を急がない
     - 解決を求める人:「どんな人なら話せそうか」など、人につながる小さな一歩を一緒に考える
   - 理由をさらに掘り下げない
   - そのあとも会話を続ける

### 3-5 チップの共通の決まり

- サーバの応答に `choices: [{id, label}]` と `choice_set` を付けられるようにする
- 画面は、AIの返事の下にボタンとして並べる。押したら、そのラベルを相談者の発言として表示し、`choice_id` をサーバに送る
- **選ばずに自由に書いてもよい**
- 同じ組は1回の会話で1回まで(スケーリングは2-1のとおり)。2つの組を続けて出さない
- 選んだ内容は `messages` に `choice_set` と `choice_id` で記録し、管理画面で見えるようにする

## 4. 終わり方

嶋先生:「危機のときは、絶望で終わらせないことがすごく大事。機械もあかんやん、何に頼ってもダメなんだってなったら、その人の選択肢がすごく狭まってしまう」

### 4-1 共通の決まり

- **危機の会話は、AIから終わらせない**。3章の分岐のあとも会話を続ける
- 「これ以上はできない」「ここでは扱えない」のように、AIの限界で区切る言い方をしない
- 終わるのは、本人が終わりの合図を出したときだけ

### 4-2 段階ごとの終わり方(本人が終わりの合図を出したとき。仮)

| 段階 | 終わり方 |
|---|---|
| 0 | 「あ、よかったね。また何かあったら、いつでもどうぞ」(石田先生の逐語) |
| 1 | 労い+「またここに来てね」+窓口の場所を一言 |
| 危機のあと | 下の文面 |

**危機のあとの終わり方(仮・嶋先生の逐語に基づく)**
> 今日のやり取り、きっとすごくエネルギーを使ったと思う。今日は一旦ゆっくり休んでね。AIにできるのは、こうしてあなたの話を聞いて、あなたを応援し続けることなんだ。またよかったら、ここに来て話そうね。

- 窓口の表示は残す
- 「応援し続ける」という内容は、同じ会話や次の来訪で何度伝えてもよい。ただし**言い回しは毎回変える**(3案用意し、同じ文を続けて出さない)

## 5. 「大丈夫」を文字どおりに受け取らない

嶋先生:「大丈夫って言葉を使う時は、ほんまにオッケーっていうよりも、もう結構ですっていう時によく使う」

- 段階2のときの「大丈夫」は、**キーワードによらない否定**として扱う(1-2)。下げるにはスケーリングで1を選ぶ必要がある
- 生成の指示に次を加える
  - 「大丈夫」を「よかった」「安心した」で受けない
  - 「どうしてそう思うの?」と掘り下げない(嶋先生:AIが担いすぎ)
- 段階1以上のときに、「大丈夫」の直後のAIの返事に「よかった」が含まれていたら、出力チェックで記録する(作り直しはせず、記録のみ)

## 7. 検証

1. **オフライン(費用なし)**
   - 段階を下げる条件の表(1-1)を、すべての組み合わせでテストする
     - 明示的な否定×スケーリング1〜5、キーワードによらない否定×スケーリング1〜5、スケーリングを選ばなかった場合
     - 下げてよいのは、明示的な否定×1・2と、キーワードによらない否定×1の3通りだけであること
   - 念押し(「冗談じゃない」など)が否定として数えられないこと
   - 段階1から0に下がらないこと。下げても通知と記録が残ること
   - 3通目の答えの3つの分岐と、「話したくない」→組B→組Cの流れ
   - チップの組が続けて出ないこと
   - 仮の文面と選択肢のラベルが、すべて出力チェックを通ること
2. **無料枠**
   - 否定の検出を、開発用の文で確かめる。11章のA・B・Cの例、念押し(「冗談じゃない」「本気だよ」)、絶望感の表現(「もういい、どうせ」)、「死にたいとか冗談だよ」を含める
   - Aの語が、危機のキーワード(「死にたい」「消えたい」)に誤って当たらないことを確かめる
3. **有料のペルソナテストは、心理士の確認で文面が決まってから**1回だけ回す。そのときのペルソナ:
   - B6 心配してほしい子:打ち明けのあと「なんでもない」→ スケーリングで4を選ぶ(下がらない)→ 3通目で「話したくない」→ B2 → C6
   - B7 ふつうに話したい子:打ち明けのあと「冗談だよ」→ スケーリングで2を選ぶ(1段階下がる)→ 別の話を続ける
   - B8 選ばない子:打ち明けのあと「もういい」→ チップを選ばず自由に書き続ける(下がらない)
   - B1・B5 も、チップがある前提で回す。生徒役が選ぶ選択肢は、ペルソナ定義で決めておく

## 8. 守ること

- 段階を下げるのは、1-1の2つの場合だけ。それ以外では下げない
- 下げるのは1段階だけ。段階1から0には下げない。通知と記録は取り消さない
- 「ふつうの会話に戻る」ボタンは作らない
- 危機の会話は、AIから終わらせない
- チップは押しつけない。いつでも自由に書ける状態を保つ
- 文面と選択肢は仮。心理士の確認前に本番で有効にしない
- 採用したら、CLAUDE.md に次を、根拠(嶋先生 10/7)とともに書き足す
  - 段階を下げる条件(否定の種類×スケーリング)
  - 危機の文面に「重い」を使わない
  - 危機の会話は、相談先や大人に話したいかの問いから分岐して続け、AIから終わらせない
- 選んだスケーリングと選択肢は、研究のデータとしても使うので、必ず記録する
