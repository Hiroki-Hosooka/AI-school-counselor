# 心理士さんの採点の前に入れる修正

## 0. 前提

- 明日、心理士さんに会話のログを採点していただく。**今夜のうちに修正を終え、版を固定する**
- 最優先は、**新しい不具合を入れないこと**。大きな作り直しはしない。迷ったら入れない
- 1章の項目は、上から順に入れる。1つ入れるごとに、5章の確認を流す
- 設計の確認は省略してよい。ただし、入れた変更は一覧にして報告すること
- 既存の指示書(`fix-after-shima4.md`・`top-screen-intake.md`)のうち、ここに書いたもの以外は、明日以降に回す

---

## 1. 必ず入れる(上から順に)

### 1-1 採点に使う環境の設定

- 段階ごとの応答(`CRISIS_RESPONSE`)は無効のまま。採点に使う環境でも無効
- 開発用の表示(4つの円、重心、関わりの型、接続済み、設定と記録)と、返事ごとの「この返答の評価」は、採点に使う環境では**表示しない**。トップ画面の作り直しが終わっていなくても、表示を消すことだけは入れる

### 1-2 同じ固定の文を、同じ会話で2回出さない

- 2回目のはっきりした打ち明けには、1回目と違う短い固定の1通を出す
- 3回目以降は、危機のあとの指示つきの生成で返す
- 職員への通知と記録は、これまでどおり毎回

### 1-3 インテークの答えとチップの選択を、危機の判定にかけない

- 数字やカテゴリの答え、チップの選択は、判定の対象から外す
- 通常の状態の分類器のプロンプトは変えない

### 1-4 気がかり(段階1)では、生徒に見える固定の文を出さない

- 気がかりや、その積み重なりでは、固定の文を出さない。気をつける指示を付けた生成で返す
- 気づかいのカードは、1回の会話で1回まで
- 記録・見守り・画面下の窓口はそのまま

### 1-5 返事の長さと言い回し(プロンプトの指示だけ)

プロンプトに次を加える。出力チェックの追加は、時間があれば2章で行う。

- ふだんの返事は1〜2文。相談者の発言が短いときは短く返す
- 「ありがとう」(教えてくれて・書いてくれて・話してくれて)は、1回の会話で要所の1〜2回まで
- 「頑張ってきたんだね」「しんどいよね」のような、誰にでも言える受け止めを繰り返さない
- 相談者が言っていない強い言葉(すり減る、限界、逃げ場など)を足さない
- 謝るときは一度だけ短く。自分を責める言い方をしない。相談者が謝ってきたら「謝らなくて大丈夫だよ」と返し、話を相談者に戻す
- 「本当にすごいことだと思う」のような、評価する言葉を使わない

### 1-6 受け止めのみ2回までが働いているかの確認

- ログ 86130eef では3回続いていた。働いていない理由を確かめ、すぐ直せるなら直す。直すのに作り直しが必要なら、報告だけにする

## 4. 採点用のログの書き出し

- 生徒の画面に表示されたやり取り**だけ**を書き出す形式を用意する。内部の判定(型・重心・段階など)は含めない
- 会話ごとに番号を付け、**どの版の会話かがわからないようにする**(ファイル名やログの中に版や日付を書かない)。番号と版の対応は、別のファイルに残す
- 1会話1ファイル。印刷して読める形(Markdown か PDF)
