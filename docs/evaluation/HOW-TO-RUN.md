# 採点の会話の動かし方(人が行う手順)

このフォルダ(評価専用のフォルダ)で、Claude Code の新しい会話を開いて採点します。
採点の会話は、採点基準(`rubric.md`)とログ(`logs/`)だけを見ます。プロジェクトのフォルダの中では開かないでください。

## 0. 始める前に(毎回)

1. `echo $ANTHROPIC_API_KEY` が空であること(設定されていると、プランの代わりに API の料金がかかります)
2. Claude の設定の「Help improve Claude」がオフであること(テストのログでも、要配慮の内容を含むため)
3. `~/.claude/CLAUDE.md` に、このプロジェクトの設計の話が書かれていないこと(採点の会話がそれを読むため)
4. このフォルダが、プロジェクトのフォルダの**外**にあること(親のフォルダに CLAUDE.md が無いこと)
5. 最初の1回だけ: 会話を開いたら `/status` でプランでログインしていることと、モデルの名前を確かめて控える。
   使用量の表示(Claude の設定の使用量)を、採点の前と後で控える

`.claude/settings.json` で、採点の会話が読めるのは `rubric.md`・`logs/`・`results/` だけ、書けるのは `results/` だけにしてあります
(コマンドの実行・Web の検索と取得・ほかのエージェントは止めています)。許可していない操作は、確認なしで断られます(`dontAsk`)。
最初の1回だけ、会話で「../ にあるファイルを1つ開いて中身を見せて」と頼み、断られることを確かめてください(ファイルの名前の一覧は見えることがありますが、中身は読めません)(確かめたら、その会話は閉じて新しい会話で採点します)。

## 1. 採点(3回。それぞれ新しい会話で)

`logs/` は10件ずつ `part-a/`・`part-b/` … に分けてあります。**part ごと・回ごとに、新しい会話を開いてください**
(前の採点を覚えていると、引きずられるため)。

1. このフォルダで `claude` を起動し、新しい会話を開く
2. 次をそのまま伝える(part と run の部分だけ変える):

   > rubric.md を読み、logs/part-a/ のすべてのログを採点して、results/run1/ に書き出してください

3. 終わったら会話を閉じる(`/exit`)。次の part も新しい会話で
4. run1 がすべての part で終わったら、run2・run3 も同じく新しい会話で

## 2. 終わったら

- `results/` のフォルダごと、実装の会話に渡してください(zip にしてアップロード)。
- あわせて、採点に使ったモデルの名前と、使用量(前と後)を伝えてください。
