## 2. 段階ごとの応答(仮・既定オフ。`CRISIS_RESPONSE=staged` のときだけ)

### 2-1 危機の応答の流れ

1. **1通目**: 受け止めだけ(+折りたたみの窓口)
2. **2通目「心配」**: 吹き出しを3つ、1.5秒おきに1つずつ出す(一度に詰め込まない。T30)。3つ目に窓口のカード
3. **3通目**(2通目と同じターン): 下の相談先や、まわりの大人に話してみたいか(3案。既定は案A)
4. **答えで分ける**
   - 前向き・どちらでもない → 一言で流れを終える
   - 後ろ向き → 選択肢のチップ(組B)。B1「このやり取り自体が、いまはちょっとうっとうしい」→ 深追いしない指示で生成 /
     B2「人とつながるのはおっくう。でも、もうちょっと聞いてほしい」→ 話しにくい理由のチップ(組C。C1〜C7。「信用できる大人があまりいない」「話したら崩れそうでこわい」など)→ 選んだ内容を受け止める一言(V23「書かせるより、ポチって押す方が負担が軽い」)
5. そのあとは危機のあとの指示つきの生成。チップはどれも押さなくてよく、自由に書いたら生成で受ける

「どんなところが話しにくい?」の問いは消した。

### 2-2 否定と「段階を下げる」こと(以前の「引き下がり」を置き換えた)

- **否定の種類**: A 生きたい気持ち(死にたくない・生きたい)/ B 冗談・取り消し(冗談・うそ・ネタ)/ C 最小化・引き下がり(なんでもない・忘れて・大丈夫)。
  念押し(冗談じゃない・本気だよ)と絶望感(もういい、どうせ)は否定に数えない
- **否定が出たら、気持ちのスケーリング**(5段階のチップ)で今の気持ちを選んでもらう。1回の会話で2回まで
- **段階を下げるのは2つの場合だけ**: A・B でスケーリングが1か2 / C でスケーリングが1。下げるのは段階2 → 1 の1段階だけ。
  段階1から0には下げない。通知と記録は取り消さない。下げたあとに危機のサインが出たら段階2に戻して通知
  (V19・V20「死にたい気持ちと死にたくない気持ちのどちらも率直な気持ち」)
- 「死にたいとか冗談だよ」は通知する。比喩・強調の「死にたい」(「テストやばすぎて死にたいって意味ね」)は通知しない

### 2-3 終わり方

- 危機のあと: 生成した区切りの返事のあとに、固定の終わりの一言(3案を人ごとに回す)を足す。労い+休んでね+また話そうね(V25・V26)。「いつでも」は言わない
- 段階1: 労い+「またここに来てね」+窓口の場所を一言

### 2-4 DB・画面

- `db/schema.sql` 14節(チップ・スケーリング・否定の種類・下げたか・危機の種類・終わりの一言の番号など)。**Supabase で実行済み**
- 画面: チップのボタン、吹き出しを間をおいて表示。管理画面: チップ・選んだもの・否定の種類・スケーリング・下げたかを表示

## 3. 危機キーワード v3(2026年10月10日に採用・既定)

- **表記ゆれに強くした**: カタカナ→ひらがな、記号・小書きの母音・促音を除いて照合(しにたーい・死にてえ・キエタイ・タヒにたい)
- **段階2に足した語**: 崩した語尾・名詞化(死にたみ)、受動的な表現(朝が来なければ・生まれなければよかった・死んだほうがまし)、
  自傷・服薬(アムカ・レグカ・OD)、虐待・性被害の語
- **段階1(キーワードの床)を新しく作った**: 日常でも使う語を段階2から段階1に下げた(生きてる意味がない・楽になりたい・助けて・単独の「触られ」・性的・「全部」の無い終わりにしたい)。
  「怒鳴られ」はキーワードから外して分類器に任せた
- 【要確認】の語(伏せ字・俗語)は心理士さんの確認まで仮
